# 寒武纪（688256）盘中分析

一个单页网页，交易时段每分钟刷新一次寒武纪的分时数据，在浏览器里计算指标、生成信号和文字解读。数据源和托管全部免费。

## 页面内容

- **分时走势**：价格、均价线（VWAP）、昨收线、每分钟成交量，关键信号标在图上
- **相对强弱**：寒武纪与科创50 的当日涨跌幅对比
- **资金流向**：主力 / 超大单 / 大单 / 中单 / 小单的当日累计净流入
- **行情**：开高低收、成交量额、换手率、量比、外盘内盘、涨跌停价、市值、PE/PB
- **盘中指标**：偏离均价、日内位置、近 30 分钟涨跌、近 5 分钟量能倍数、1 分钟 RSI(14) 和 MACD、相对科创50 的超额涨幅、与指数的分钟收益相关系数、主力净流入、主动买入占比
- **五档盘口**
- **信号列表**：穿越均价线、MACD 金叉/死叉、主力资金转向、跑赢/跑输指数（以上需连续 2 分钟确认）；放量（≥ 近 30 分钟均量 3 倍）、创日内新高/新低、RSI 进入超买/超卖区（同类间隔 ≥ 10 分钟）。交易中尚未走完的那一分钟不参与判断
- **交易建议**：见下一节
- **浏览器提醒**：点“开启信号提醒”后，出现新信号或交易建议变化时会弹系统通知（页面需保持打开）

## 交易建议

页面顶部的“交易建议”卡片按 5 个维度打分，每个维度 −2 到 +2 分，相加得到 −10 到 +10 的综合分。

| 维度 | 指标 | 规则 |
| --- | --- | --- |
| 趋势和位置 | 均价线（VWAP）、15 分钟 MA5/MA20 | 偏离均价线超过 ±0.3% 计 ±1；同一侧持续 ≥15 分钟再计 ±1；MA5 在 MA20 上方且 MA20 向上计 +1，反之 −1 |
| 动量 | 15 分钟 MACD(12,26,9)、RSI(14) | DIF 在 DEA 上/下方计 ±1，DIF 同时在零轴上/下方再计 ±1；RSI ≥75 计 −1，≤25 计 +1 |
| 量能 | 近 30 分钟量价、近 5 分钟量能 | 上涨时成交量比下跌时多 20% 以上计 +1，反之 −1；近 5 分钟均量 ≥ 当日均量 2 倍时按这 5 分钟的涨跌计 ±1 |
| 资金 | 东方财富主力净流入 | 当日累计净流入占成交额超过 ±3% 计 ±1；近 30 分钟净流入占同期成交额超过 ±5% 计 ±1 |
| 相对强弱 | 科创50（其他股票用沪深300） | 近 30 分钟跑赢/跑输指数 0.5 个百分点以上计 ±1；近 60 分钟与指数的相关系数 >0.6 时，指数近 30 分钟涨跌超过 ±0.3% 再计 ±1 |

综合分 ≥ +4 为偏多，≤ −4 为偏空，其余为观望。9:45 之前门槛提高到 ±6。新结论要连续 2 分钟成立才切换。

页面上可以选择持仓情况，选择会保存在浏览器里：

- **空仓**：可考虑买入 / 观望 / 不宜买入。14:50 之后不建议新开仓（T+1）；接近涨停，或者振幅超过 8% 且价格在日内高位时，不建议追高。
- **持仓**：继续持有 / 持有观察 / 建议减仓 / 触发止损。止损位取“成本价下方 X%（默认 3%，成本价可不填）”和“15 分钟前日内低点下方 0.2%”中较高的那个。止损触发后当天不再撤销。
- **底仓做T**：
  - 可高抛：综合偏空，或者 15 分钟 RSI ≥70 且价格高出均价线 1.5% 以上。
  - 可低吸：综合偏多且价格高出均价线不超过 0.5%，或者 15 分钟 RSI ≤30 且价格低于均价线 1.5% 以上。

每次刷新时，页面会把当天的数据按分钟回放一遍。每一分钟只用那一刻能看到的数据，所以“今日结论变化”记录是固定的，刷新页面不会改写历史结论。交易中还没走完的那一分钟、还没走完的那根 15 分钟 K 线都不参与计算。

**局限**：权重和阈值是按经验定的，没有经过回测验证。主力资金是东方财富按单笔金额估算的。数据有 1–2 分钟延迟。

地址栏加 `?code=600519` 可以换成其他 A 股；科创板股票对比科创50，其他对比沪深300。

## 结构

```
public/            前端静态文件
  index.html
  app.js           拉数据、渲染、刷新调度、提醒
  analysis.js      指标和信号计算（纯函数）
  advice.js        交易建议打分（纯函数）
  style.css
  vendor/          TradingView Lightweight Charts 5.2.1（本地托管，避免 CDN 在国内加载慢）
src/
  worker.js        Cloudflare Worker：/api/snapshot、内存缓存、交易时段判断
  sources.js       东方财富 / 腾讯接口的抓取与解析
server.mjs         本机 Node 运行入口，复用 worker.js 的逻辑
wrangler.toml      Cloudflare 部署配置
```

前端只请求自己的 `/api/snapshot`，后端再去请求行情源。这样做有两个原因：行情接口不支持浏览器跨域请求；后端缓存 50 秒，打开再多标签页，对行情源的请求也只有每分钟 1 次。

刷新频率：交易中和集合竞价每 60 秒一次，午休每 5 分钟一次，收盘后每 10 分钟一次。标签页切到后台时暂停刷新。

## 运行方式

需要 Node.js 18 或以上。

### 方式一：本机运行（最简单，国内网络推荐）

```bash
npm install
npm start
# 打开 http://localhost:8787
```

### 方式二：部署到 Cloudflare Workers（免费，有公网地址）

```bash
npm install
npx wrangler login      # 浏览器里登录 / 注册 Cloudflare 账号
npm run deploy          # 输出 https://cambricon-monitor.<你的子域>.workers.dev
```

免费套餐每天 10 万次请求。一个打开的页面每分钟请求 1 次，一个交易日约 240 次。

**注意**：`*.workers.dev` 域名在中国大陆经常被干扰，可能打不开。如果你在国内，可以选本机运行，或者在 Cloudflare 上给 Worker 绑定自己的域名（域名本身需要付费）。

## 数据源

| 数据 | 主源 | 备用源 |
| --- | --- | --- |
| 实时报价 | 东方财富 push2delay | 腾讯 qt.gtimg.cn |
| 1 分钟 K 线（个股、指数） | 东方财富 push2his | 腾讯分时 ifzq.gtimg.cn |
| 15 分钟 K 线（近 8 个交易日） | 东方财富 push2his | 腾讯 ifzq.gtimg.cn |
| 资金流向 | 东方财富 push2delay | 无 |
| 五档盘口 | 腾讯 qt.gtimg.cn | 无 |

- 这些都是非官方公开接口，字段和地址随时可能变化。主源失败会自动切到备用源，页面底部会写明这次用了哪个源；没有备用源的数据缺失时，页面顶部会出现提示。
- 海外 IP 访问东方财富 `push2` 会被重定向到 `push2delay`，所以代码里直接用 `push2delay`。实测它的报价时间戳和当前时间一致，没有明显延迟。
- 成交量单位：东方财富是“手”，腾讯对科创板用“股”、对其他板块用“手”。代码用“成交额 ÷ (量 × 价)”自动换算，页面上统一显示“股”。
- 这些数据只能个人使用。页面如果要公开给别人看，需要正规的行情授权。

## 已验证 / 未验证

- 已验证：在海外服务器上，用 Node 和 wrangler 本地运行时（workerd）都能完整拿到报价、分钟线、资金流、盘口和指数数据，页面能正常渲染。
- 未验证：部署到 Cloudflare 线上之后，东方财富和腾讯是否会限制 Cloudflare 的出口 IP。如果线上请求失败，可以改用本机运行。
